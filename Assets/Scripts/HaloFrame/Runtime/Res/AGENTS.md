# Assets/Scripts/HaloFrame/Runtime/Res / AGENTS

## Overview
Resource loading is split into:
- `ResourceManager`: resource-level reference counting + dependency loading via `AssetMap.json`
- `BundleManager`: AssetBundle-level loading + dependency resolution via `main` manifest
- `HotUpdateManger`: runtime version/map fetch + diff + download into sandbox

## Data Files
Generated by the editor build pipeline (`Builder.cs`):
- `GameVersion.json` (version + remote address)
- `AssetMap.json` (per-resource `AssetInfo`: res url, ab url, deps, md5, size, version)

Runtime locations:
- First run fallback: `Resources.Load<TextAsset>("GameVersion")` and `Resources.Load<TextAsset>("AssetMap")`
- Sandbox override: `PathTools.LocalGameVersionPath` and `PathTools.LocalAssetMapPath` under `Application.persistentDataPath/<Platform>/`

## ResourceManager (High Level)
`Assets/Scripts/HaloFrame/Runtime/Res/ResourceManager.cs`:
- `LoadInternal(url, async)` caches by url, tracks `reference`, and loads dependencies from `GameConfig.RemoteAssetMap[assetUrl].Dependency`.
- Async loads are polled in `Tick()`; completion resolves a `ResourceAwaiter`.
- Unload is delayed via `waitUnloadList`; unloading cascades to dependencies.

## BundleManager (High Level)
`Assets/Scripts/HaloFrame/Runtime/Res/BundleManager.cs`:
- Initializes from `<bundleRootDir>/main` (main manifest asset bundle) and reads `AssetBundleManifest`.
- Loads direct AB dependencies via `manifestAB.GetDirectDependencies(url)`.
- Unload uses ref-count; cascades to dependencies.

## HotUpdateManger Flow
`Assets/Scripts/HaloFrame/Runtime/Res/HotUpdateManger.cs`:
1) `Enter()` loads local `GameVersion` + `AssetMap` (sandbox first, else Resources).
2) `ReqRemote()` fetches remote `GameVersion.json` and `AssetMap.json` from `GameConfig.HotUpdateAddress`.
3) `CheckHotUpdate()` diffs `LocalAssetMap` vs `RemoteAssetMap` by `Md5` and returns `(AssetInfoSet, totalSize)`.
4) `StarHotUpdate(...)` enqueues downloads:
   - AB files: `RemoteABUrlPrefix + item.ABUrl` -> `DownloadABPathPrefix + item.ABUrl`
   - Main manifest file: downloads `"main"` as well
5) On complete: writes remote version/map to sandbox via `PathTools.LocalGameVersionPath` and `PathTools.LocalAssetMapPath`.

## Gotchas
- `CompareVersion(...)` forces update when sandbox version file does not exist.
- Path construction relies on `PathTools.Platform` and `PathTools.Combine` (slashes).
- `ReqRemote()` has a TODO for retry/timeout; failures `yield break` without fallback.
